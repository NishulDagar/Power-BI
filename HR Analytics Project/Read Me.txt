#HR Analytics Project for Beginners.

1.) In this project we will learn how to connect MS SQL Server Database to Power BI and directly used data from real data. 
2.) We will see how to clean data into SQL and then explore some power bi and power query function.
3.) As this project is for beginners only so we will use very basic charts and very simple DAX if needed.


create a table into MS SQL Server.
CREATE TABLE Hr_Record (
    id VARCHAR(20) PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    birthdate DATE,
    gender varchar(50),
    race VARCHAR(50),
    department VARCHAR(100),
    jobtitle VARCHAR(100),
    locations VARCHAR(100),
    hire_date DATE,
    term_date DATE,
    location_city VARCHAR(100),
    location_state VARCHAR(50)
);

insert the data into that table.
before inserting the data into table have a look on excel file data like first name and last name column format and date format.
clean the data accordingly.

1. Rename column id.
exec sp_rename 'hr_record.id','Emp_id', 'column'

2.Rename column from race to ethnicity.
exec sp_rename 'hr_record.race','Ethnicity', 'column'

3.Drop Unnecessary columns.
alter table hr_record
drop column termdate

4.Add column Age.(so that we can identify the record of those employees who is less than 18 yrs).
alter table hr_recod
add Age int.

5. Insert data into Age column.
update HR_Record
set age = DATEdiff(year,birthdate, GETDATE())

6.Identify employees whose age is less than 18 yrs.
select count(*) from HR_Record
where age<18

7.Add age group column.
alter table hr_record
add Age_Group varchar(20)

8.Insert data into Age_group.
update HR_Record
set Age_group = case when age between 18 and 30 then 'Young'
		when age between 31 and 50 then 'Adult'
		else 'Mature' end


9.Data cleaning is done now upload the data into power BI from SQL.
BRD(Business Requirement Document) for this project are:
i.)Find age distribution(Young, Adult, Mature).
ii.)Gender Distribution(Male, Female, None).
iii.)Ethnicity Distribution.
iv.)Work Setting Distribution(Work From Home or Office).
v.)Gender Across Department.
vi.)Top 3 Work From Home.
